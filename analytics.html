    What we could make easier

    None of this is about how anyone worked — it is about how the project is arranged, and every one of them has an easier arrangement. The bar shows the cost in one picture.

    6 saves that built something 0 saves that only untangled edits (0%)

    1. One file, everyone in it

      All 13 tiles share a single file, which is why 0 of 6 saves (0%) exist only to untangle two people’s edits.

      Easier would be: One file per tile, stitched together automatically.

    2. Publishing fails when two people save at once

      Each of those untangling saves began as a refusal on someone’s screen, with no obvious next step.

      Easier would be: A single publish command that fetches, replays and sends.

    3. Nothing protects one tile from another

      The rule is “edit only your own block”, but nothing enforces it — 0 people have saves that reach into someone else’s tile or the shared theme. Useful to know now rather than at 100 tiles.

      Easier would be: Ownership per tile, so a wrong edit is caught before it publishes, not after.

    4. Finished drafts have no road to the page

      0 of 0 draft copies are already published but never cleared, so only 0 still hold live work — easy to lose your own in the noise.

      Easier would be: Clear each draft automatically once published.

    5. Name settings unset, so credit splits

      0 people appear under two names, and some saves carry a laptop default like yourname@macbook.local that links to no account.

      Easier would be: Set name and email once during setup.

    6. No preview before it is public

      There is no way to see your tile between saving and going live, so the safe move is to try less.

      Easier would be: A one-command local preview.

    The words, in plain English

    The tools have their own vocabulary. Here it is translated, with the technical word beside it.

    Savecommit
    One batch of finished edits, stored with your name on it.
    Publishpush
    Sending your saves to the shared page, where everyone can see them.
    The shared pagemain
    The one official copy that the live website is built from.
    Draft copybranch
    Your own private version. Safe to experiment in; invisible to others until you publish.
    Untanglingmerge
    The extra work of combining your edits with someone else’s when you both changed the same file.
    Request for reviewpull request
    Asking someone to check and approve your work before it goes live.
